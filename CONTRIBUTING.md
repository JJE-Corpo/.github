# Contributing to JJE-Corpo Projects

Thank you for your interest in contributing! We appreciate your time and effort.

## How to Contribute

1. **Fork** the repository you want to contribute to.
2. **Create a branch** from `main` with a descriptive name (e.g., `fix/bug-description` or `feature/new-feature`).
3. **Make your changes**, following the coding style of the project.
4. **Write or update tests** to cover your changes where applicable.
5. **Open a pull request** with a clear description of what you changed and why.

## Reporting Issues

- Search existing issues before opening a new one.
- Provide a clear title and description.
- Include steps to reproduce the issue if applicable.

## Code of Conduct

Please be respectful and constructive in all interactions. We are committed to providing a welcoming environment for everyone.

## Questions

If you have questions, open an issue in the relevant repository and we'll do our best to help.
